# QNX Smart Traffic Controller

**A Real-Time Adaptive Traffic Signal Control System using QNX RTOS**

## Overview

QNX Smart Traffic Controller is a real-time traffic management system designed for a T-junction. It dynamically adjusts traffic signal timings based on vehicle density using Webster's optimization algorithm and provides priority passage for emergency vehicles such as ambulances.

The system consists of a C-based traffic controller running on QNX RTOS and a Python Pygame simulator that communicates with the controller over TCP.

## Key Features

- **Adaptive Signal Timing:** Dynamically calculates green signal durations based on real-time vehicle counts using Webster's algorithm.
- **Emergency Vehicle Priority:** Provides priority signal access for emergency vehicles through pre-emption logic.
- **Real-Time Scheduling:** Uses POSIX threads, priority-based scheduling and event-driven execution.
- **Inter-Process Communication:** Uses POSIX message queues for communication between controller tasks.
- **Safety Mechanisms:** Implements a finite state machine, conflict detection and all-red fail-safe protection.
- **Live Simulation:** Visualizes traffic flow, signal states and emergency vehicle movements through a Pygame interface.
- **TCP Communication:** Connects the simulator to the QNX controller for live data exchange and status monitoring.

## System Architecture

The project consists of two main components:

| Component | Technology | Responsibility |
|---|---|---|
| Traffic Controller | C, QNX RTOS | Signal control, adaptive timing, emergency handling and safety management |
| Traffic Simulator | Python, Pygame | Traffic visualization, vehicle generation and communication with the controller |

**Communication Flow:**

```text
Vehicle Simulation
       |
       | Vehicle Counts / Emergency Requests
       v
   TCP Connection
       |
       v
QNX Traffic Controller
       |
       | Signal Plans / Status
       v
Pygame Traffic Simulation
```

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/diajay9785/qnx-smart-traffic-controller.git
cd qnx-smart-traffic-controller
```

### 2. Run the Simulator

Install the required dependencies:

```bash
cd simulator
pip install -r requirements.txt
```

Run the simulator using the mock controller:

```bash
python main.py --mock
```

### 3. Run with QNX RTOS

Build the controller in a QNX Software Development Platform environment:

```bash
qcc -Vgcc_ntoaarch64le -O2 -Wall -o qnx_traffic_controller controller/qnx_traffic_controller.c -lsocket
```

Deploy the executable to the QNX target and start the controller. Configure the simulator with the target device's IP address to establish TCP communication.

## Project Scope and Limitations

- Designed and demonstrated for a simulated T-junction.
- Vehicle density is generated by the simulator rather than a physical camera.
- The system communicates signal states over TCP; it does not directly control physical traffic lights.
- This is a development prototype and is not certified for real-world traffic deployment.
